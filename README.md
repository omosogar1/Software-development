# 🏦 Kelly Bank - Python CLI Banking System

A complete command-line banking system built in Python in 7 days. Supports real account management, persistent storage, and transaction history.

**Built by:** Emokiniovo Kelly Omosogar | Warri, Delta State, NG
**Stack:** Python 3.13, JSON, datetime

### ✨ Features
- Check Balance
- Deposit & Withdraw with balance validation
- Transfer to other accounts (auto-creates recipient)
- Transaction History with timestamps
- Persistent storage using `bank_data.json` & `transactions.json`

### 🚀 How to Run
```bash
python bank_app.py
